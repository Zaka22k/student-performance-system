Карта смещений

Для feDisplacementMap: R = смещение по x, G = смещение по y, 128 означает «без смещения».

Маска блика

Белый слой по контуру, лежит поверх стекла. Показан на тёмной подложке.

Что считается

  1. Высота стекла на расстоянии d от края: h(d) = H · f(d / B), где B ширина кромки, H высота, f один из профилей. Squircle: f(x) = (1 − (1 − x)⁴)^¼.
  2. Наклон s = H · f′(x) / B. Угол падения θ₁ = atan |s|, угол в стекле θ₂ = asin(sin θ₁ / n).
  3. Смещение на фоне: Δ = sign(s) · h · tan(θ₁ − θ₂). Для выпуклого профиля оно направлено внутрь панели, для вогнутого наружу.
  4. Значения нормируются на максимум и кодируются в цвет: R = 128 + nx · m · 127, G = 128 + ny · m · 127, где (nx, ny) единичный вектор внутрь от ближайшей точки контура.
  5. Блик: I = max(cos φ, 0) + 0.5 · max(−cos φ, 0), где φ угол между нормалью контура и направлением света. Он умножается на узкую маску у края.

Для scale здесь используется 2 · max (точнее, 255/127 · max). По спецификации SVG смещение равно scale · (C − 0,5), поэтому канал 0..255 даёт диапазон ±scale/2, а не ±scale. Блик в этой демо построен мной по описанию в статье: там сказано только про подсветку по контуру с фиксированным углом света.

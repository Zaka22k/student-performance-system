# Toolbar

Панель инструментов в стиле Apple Liquid Glass для компонента `Page`. Сделана по [Apple HIG: Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars). Стекло берётся из `GlassPanel`.

## Состав

| Часть | Назначение |
|---|---|
| `Toolbar` | Контейнер с тремя зонами: leading, center, trailing. Сам фона не имеет. |
| `ToolbarGroup` | Стеклянная «таблетка» (`GlassPanel`) для двух и более кнопок. |
| `ToolbarButton` | Прозрачная кнопка для использования внутри `ToolbarGroup`. |
| `ToolbarDivider` | Тонкий разделитель между кнопками внутри группы. |
| `ToolbarSpacer` | Пробел между группами: фиксированный или растягивающийся. |
| `Page` | Уже встраивает `Toolbar` в липкую шапку и принимает проп `toolbar`. |

## Установка

1. Положите папку `Toolbar/` рядом с `Page/`, `Button/`, `GlassPanel/`.
2. Замените `Page/Page.tsx` новой версией. `Page.module.css` менять не нужно.
3. Проверьте импорт стекла в `Toolbar.tsx`: `import { GlassPanel } from "../GlassPanel"`. Если у вас другой путь, поправьте его.

## Использование через Page

```tsx
import Page from "../components/Page";
import {
  ToolbarGroup,
  ToolbarButton,
  ToolbarDivider,
} from "../components/Toolbar";

<Page
  title="Файлы"
  showBackButton
  toolbar={{
    // Две и больше кнопок: одна стеклянная группа, внутри прозрачные кнопки с разделителем.
    center: (
      <ToolbarGroup>
        <ToolbarButton aria-label="Фильтр" icon={<FilterIcon />} />
        <ToolbarDivider />
        <ToolbarButton aria-label="Удалить" icon={<DeleteIcon />} />
      </ToolbarGroup>
    ),
    trailing: (
      <>
        {/* Строка поиска уже стеклянная: в группу не оборачиваем. */}
        <SearchBox />
        {/* Одиночная кнопка: обычный GlassButton, без группы. */}
        <GlassButton aria-label="Ещё" icon={<MoreIcon />} />
        {/* Главное действие: тоже одиночная кнопка, без группы. */}
        <GlassButton>Готово</GlassButton>
      </>
    ),
  }}
>
  {/* содержимое страницы */}
</Page>
```

**Правило против «стекла в стекле».** Стеклянные элементы (`GlassButton`, ваша строка поиска) ставьте в тулбар напрямую. В `ToolbarGroup` кладите только `ToolbarButton`: у них нет своего стекла.

Кнопка «Назад» и заголовок добавляются самой `Page`. Свои элементы в leading (например, кнопку сайдбара) передавайте через `toolbar.leading`: они встанут между «Назад» и заголовком.

## Использование без Page

```tsx
<Toolbar
  leading={<GlassButton aria-label="Назад" icon={<ChevronLeftIcon />} />}
  title="Заметки"
  trailing={
    <ToolbarGroup>
      <ToolbarButton aria-label="Поделиться" icon={<ShareIcon />} />
      <ToolbarDivider />
      <ToolbarButton aria-label="Ещё" icon={<MoreIcon />} />
    </ToolbarGroup>
  }
/>
```

## API

### `Toolbar`

| Проп | Тип | Описание |
|---|---|---|
| `leading` | `ReactNode` | Левый край: назад, сайдбар. Стоит перед заголовком. |
| `title` | `ReactNode` | Заголовок текущего представления. |
| `center` | `ReactNode` | Центральная зона: частые действия. Занимает свободное место. |
| `trailing` | `ReactNode` | Правый край: действия, поиск, «Ещё», главное действие. Всегда виден. |

Остальные атрибуты `<header>` пробрасываются как есть. Роль элемента: `toolbar`.

### `ToolbarGroup`

| Проп | Тип | По умолчанию | Описание |
|---|---|---|---|
| `height` | `number` | `36` | Высота группы в px. |
| `width` | `number \| string` | `"auto"` | Ширина группы. По умолчанию по содержимому. |

Параметров стекла у группы нет: используются значения `GlassPanel` по умолчанию. Остальные атрибуты `div` и `className` пробрасываются на `GlassPanel`. Роль элемента: `group`.

### `ToolbarButton`

Прозрачная кнопка для `ToolbarGroup`. Высота равна высоте группы минус 4 px. Принимает все атрибуты `<button>` и проп `icon`. Для кнопки только с иконкой задайте `aria-label`. Размер иконки задавайте самой иконкой, цвет она наследует от текста.

### `ToolbarDivider`

Вертикальная линия 1×16 px. Ставится между `ToolbarButton` внутри группы. Без пропсов.

### `ToolbarSpacer`

| Проп | Тип | По умолчанию | Описание |
|---|---|---|---|
| `flexible` | `boolean` | `false` | `true` растягивается и раздвигает соседей, `false` даёт отступ 8 px. |

## Правила из HIG

- **Не больше трёх групп.** Группируйте по функции и частоте использования.
- **Навигация и критичные действия** (Готово, Закрыть, Сохранить) держите в отдельных, узнаваемых группах.
- **Иконки вместо текста.** Текстовую подпись оставляйте только для действий, которые плохо выражаются символом (например, «Изменить»).
- **Иконки без рамок.** Контейнер уже даёт группа, лишние обводки не нужны.
- **Группа нужна от двух кнопок.** Одиночное действие ставьте как `GlassButton`, строку поиска как есть, без обёртки.
- **Не вкладывайте стекло в стекло.** Внутри `ToolbarGroup` только `ToolbarButton`.
- **Действие с текстом ставьте в отдельную группу.** Рядом с иконкой оно сливается с ней в одно «составное» действие.
- **Главное действие одно**, оформляется отдельной кнопкой, и стоит последним в trailing.
- **Короткий заголовок**, до 15 символов. Не называйте им приложение. Если заголовок избыточен, не передавайте его.
- **Кнопка «Назад»** только со стандартным символом, без текстовой подписи «Назад».
- **Не красьте тулбар и не добавляйте свой фон.** Пусть цвет задаёт содержимое под ним, а границу даёт градиент шапки.
- **Выбирайте элементы осознанно.** Менее важные действия уберите в меню «Ещё».

## Настройка

- **Высота групп.** По умолчанию 36 px, задаётся пропсом `height` у `ToolbarGroup`. Общее значение по умолчанию — константа `TOOLBAR_GROUP_HEIGHT` в `Toolbar.tsx`. Она должна совпадать с высотой `GlassButton`, чтобы группы и одиночные кнопки стояли в один ряд.
- **Отступы.** Зазор между зонами и группами (12 px) и внутренние отступы группы заданы в `Toolbar.module.css`.

## Ограничения

- Автоматического overflow-меню при сужении окна нет. Лишние действия добавляйте в меню «Ещё» вручную.
- Преломление работает только в Chromium. В остальных браузерах `GlassPanel` использует обычное размытие, блик по краю остаётся.
- Строка поиска не входит в компонент: вставляйте свой компонент прямо в `trailing` или `center`, его ширину задавайте у него самого.

# GlassPanel: инструкция

Стеклянная панель, которая преломляет всё, что находится за ней. Состоит из трёх файлов в одной папке:

| Файл | Что внутри |
|---|---|
| `GlassPanel.tsx` | Сам компонент (`"use client"`) и единственное место с базовыми настройками, `GLASS_DEFAULTS` |
| `liquidGlass.ts` | Математика: таблица преломления, карта смещений, маски блика и тени по краю (без React) |
| `index.ts` | Общий экспорт |

Нужен React 18 или новее (используется `useId`). Полностью совместим с Next.js App Router (SSR).

```tsx
import { GlassPanel } from './glass-panel';
```

## 1. Главное правило: за стеклом должно что-то быть

Стекло ничего не рисует само. Оно искажает то, что лежит под ним. Поэтому:

- На однотонном фоне эффекта не видно. Нужны картинка, градиент, текст или узор.
- Панель и фон должны быть в одном контексте наложения. Если у родителя панели есть `opacity < 1`, `filter`, `mask` или `will-change: transform`, браузер «обрезает» фон, и стекло видит только содержимое этого родителя.
- Эффект преломления работает в Chrome и других браузерах на Chromium (кроме iOS). В Safari и Firefox вместо него включается обычное размытие (`fallbackBlur`). Блик, контур и внутренняя тень рисуются обычными слоями панели, поэтому видны во всех браузерах.

## 2. GlassPanel в разметке

### Минимальный пример

```tsx
<div
  style={{
    position: 'relative',
    minHeight: 400,
    backgroundImage: 'url(/bg.jpg)',
    backgroundSize: 'cover',
  }}
>
  <GlassPanel style={{ position: 'absolute', left: 40, top: 40 }}>
    Привет
  </GlassPanel>
</div>
```

Позиционирование задаётся обычным `style` или `className`, как у любого блока. Панель по умолчанию `inline-flex` и центрирует содержимое.

### Размеры

`width` и `height` принимают число (px), любой CSS-размер или `'auto'`:

```tsx
<GlassPanel width={320} height={160} />             {/* по умолчанию */}
<GlassPanel width="100%" height={72} radius={20} />  {/* на всю ширину */}
<GlassPanel width="auto" height="auto" style={{ padding: '12px 20px' }}>
  Метка
</GlassPanel>
```

Панель сама измеряет свой размер и пересобирает карты, поэтому процентные и автоматические размеры работают.

### Форма

- `radius` задаёт скругление в px. Значение больше половины короткой стороны даёт «таблетку» или круг.
- `bezel` (ширина кромки) не может быть больше половины короткой стороны, лишнее обрезается автоматически.

### Все параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `profile` | `'squircle'` | Форма кромки: `'squircle'`, `'circle'`, `'concave'`, `'lip'` |
| `bezel` | `30` | Ширина зоны преломления у края, px |
| `glassHeight` | `50` | Высота стекла, px. Больше значит сильнее преломление |
| `ior` | `1.5` | Показатель преломления. `1` отключает эффект |
| `strength` | `1` | Множитель смещения. `0` выключает преломление, `1.5` усиливает |
| `blur` | `0.25` | Размытие фона, px |
| `saturation` | `1.4` | Насыщенность фона, `1` без изменений |
| `specularAngle` | `-110` | Направление света в градусах. `0` справа, `90` снизу, `-110` сверху слева |
| `specularOpacity` | `0.6` | Яркость блика, 0..1 (число или CSS-переменная) |
| `specularWidth` | `2` | Толщина блика, px |
| `edgeShadowOpacity` | `'var(--edgeShadowOpacity)'` | Сила тонкого контура и мягкой внутренней тени по краю, 0..1. В `index.css` равна `0.4` для светлой темы и `0` для тёмной |
| `edgeShadowWidth` | `24` | Ширина мягкой внутренней тени, px. Число или токен. Сам контур всегда около 1.4 px |
| `outerShadowOpacity` | `'var(--outerShadowOpacity)'` | Прозрачность тени вокруг панели, 0..1. В `index.css` равна `0.1` для светлой темы и `0` для тёмной. Игнорируется, если задан `boxShadow` |
| `width` | `320` | Ширина |
| `height` | `160` | Высота |
| `radius` | `9999` | Радиус углов, px. По умолчанию «таблетка» |
| `boxShadow` | не задан | Полная CSS-тень. Если задана, заменяет тень из `outerShadowOpacity` |
| `fallbackBlur` | `24` | Размытие в браузерах без поддержки SVG-фильтра |
| `dispersion` | `0` | Хроматическая дисперсия, 0..1: красный, зелёный и синий преломляются с разной силой, на краю появляется цветная кайма. `0` отключает и экономит два прохода фильтра |

Остальные атрибуты div (`className`, `style`, `onClick`, `aria-*`) и `ref` передаются на корневой элемент.

**Цвет панели** отдельного пропа не имеет: задавайте его через `style` (`style={{ background: 'rgba(255,255,255,0.1)' }}`) или через `className` и свой CSS, токены работают как обычно. По умолчанию заливки нет.

### Светлый и тёмный вид краёв

Базовые значения в `GLASS_DEFAULTS` уже привязаны к CSS-переменным `--edgeShadowOpacity` и `--outerShadowOpacity` из `index.css`. В светлой теме включается тёмный контур с мягкой внутренней тенью (`0.4`) и лёгкая внешняя тень (`0.1`), а в тёмной теме они отключаются (`0`), оставляя только светлый блик.

При необходимости можно переопределить параметры вручную:

```tsx
<GlassPanel
  style={{ background: 'rgba(0, 0, 0, 0.04)' }}
  specularOpacity={1}
  specularWidth={2}
  edgeShadowOpacity={0.2}
  edgeShadowWidth={9}
  outerShadowOpacity={0.12}
/>
```

Контур и тень рисуются чёрным цветом, блик белым. Цвета пока не настраиваются.

### CSS-токены вместо чисел

`specularOpacity`, `edgeShadowOpacity` и `outerShadowOpacity` принимают число или строку с CSS-переменной. Токен должен раскрываться в обычное число от 0 до 1 (не в проценты):

```css
:root                { --glass-outer-shadow-opacity: 0.12; --glass-edge-opacity: 0.2; }
[data-theme='dark']  { --glass-outer-shadow-opacity: 0.5;  --glass-edge-opacity: 0; }
```

```tsx
<GlassPanel
  outerShadowOpacity="var(--glass-outer-shadow-opacity)"
  edgeShadowOpacity="var(--glass-edge-opacity)"
  style={{ background: 'var(--glass-bg)' }}
/>
```

При смене темы значения обновляются сразу, карты не пересобираются. Если нужна тень целиком из токена, передайте `boxShadow="0 14px 40px var(--shadow-color)"`, он главнее `outerShadowOpacity`.

#### Ширина внутренней тени из токена

`edgeShadowWidth` тоже принимает токен. В отличие от прозрачностей, ширина запекается в карту, поэтому при смене значения карта пересобирается (один раз на смену темы). Токен может хранить число (`24`) или длину (`24px`, `1.5rem`), работает и `calc()`:

```css
:root               { --glass-edge-width: 24px; }
[data-theme='dark'] { --glass-edge-width: 12px; }
```

```tsx
<GlassPanel edgeShadowWidth="var(--glass-edge-width)" />
<GlassPanel edgeShadowWidth="calc(var(--glass-edge-width) * 2)" />
```

Компонент перечитывает токен при изменении атрибутов (`class`, `style`, `data-*`) у `<html>` или `<body>` и при смене системной цветовой схемы. Поэтому объявляйте токен на `:root` или `body`: значение, заданное на предке панели и меняющееся отдельно, не отслеживается. Если токен не раскрылся, берётся `24`.

### Рецепты

```tsx
{/* Тёмное синее стекло */}
<GlassPanel style={{ background: 'rgba(10, 40, 70, 0.35)' }} />

{/* Сильное линзовое преломление с дисперсией */}
<GlassPanel ior={1.8} glassHeight={90} bezel={46} dispersion={0.15} />

{/* Тонкая кромка, лёгкий эффект */}
<GlassPanel bezel={14} glassHeight={24} strength={0.7} />

{/* Блик слева снизу, ярче */}
<GlassPanel specularAngle={150} specularOpacity={0.9} />

{/* Круглая кнопка */}
<GlassPanel width={64} height={64} radius={32} bezel={20} glassHeight={30} />
```

### Что лучше не делать

- **Не анимируйте `width` и `height` через CSS transition.** На каждый кадр панель пересобирает карты на canvas. Для движения и появления используйте `transform` и `opacity` на родителе.
- **Не берите профиль `concave`** на краях страницы. Он выталкивает лучи за границу панели, где фона нет, и края выглядят обрезанными. `lip` подходит для маленьких элементов вроде переключателя.
- **Не ставьте десятки больших панелей на одну страницу.** У каждой панели свои карты. Для кнопок, полей и нескольких карточек это нормально.

## 3. Частые вопросы

**Эффекта не видно.** Проверьте, что за панелью есть неоднородный фон и что у родителей панели нет `opacity`, `filter` или `mask`. Откройте страницу именно в Chrome.

**Края панели выглядят обрезанными.** Уменьшите `glassHeight` или `strength`. Слишком сильное смещение берёт пиксели из-за границ панели.

**Нужно менять параметры на лету.** Это можно делать через состояние React: карты пересобираются при каждом изменении, быстро для кнопок и небольших панелей. Для слайдеров на больших панелях лучше обновлять не чаще одного раза за кадр.

**Серверный рендер (Next.js App Router).** В `GlassPanel.tsx` уже добавлена директива `'use client'`. На сервере и при первом рендере панель показывает обычное размытие (`fallbackBlur`). Преломление включается после монтирования в браузере, ошибок гидратации нет. Внутрь `children` можно передавать Server Components.

# BarChart

Горизонтальная столбчатая диаграмма: подпись, полоса и значение в одной строке. Подходит для сравнения нескольких величин (средняя оценка по группам, распределение оценок).

Цвета полосы и дорожки, скругление и анимация берутся из токенов `index.css`, своих значений в компоненте нет.

## Подключение

```
BarChart.tsx
BarChart.module.css
index.css        // должен быть подключён в приложении: токены и классы типографики
```

```tsx
import BarChart from "./BarChart";
```

## Быстрый старт

```tsx
<BarChart
  aria-label="Средняя оценка по группам"
  items={[
    { label: "ИТ-21", value: 4.25 },
    { label: "ИТ-22", value: 3.8 },
    { label: "ИТ-23", value: null }, // данных нет
  ]}
  max={5}
  formatValue={(v) => v.toFixed(2)}
/>
```

## Свойства

| Свойство | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `items` | `{ label: string; value: number \| null }[]` | — | Строки диаграммы. `label` должен быть уникален: он служит ключом |
| `max` | `number` | наибольшее значение | Значение, которому соответствует полная полоса. Для оценок передайте `5` |
| `formatValue` | `(value: number) => string` | `String` | Подпись значения справа |
| `emptyContent` | `ReactNode` | `"Нет данных"` | Что показать, когда `items` пуст |
| `aria-label` | `string` | — | Доступное имя диаграммы |
| `className`, `style` | | | Применяются к корневому элементу |

## Поведение

- `value: null` показывается как «—» с пустой полосой.
- Ширина полосы анимируется при смене значений (токены `ControlAnimationDuration`, `ControlAnimationEasing`), при `prefers-reduced-motion` анимации нет.
- Длинные подписи обрезаются многоточием, полный текст виден во всплывающей подсказке.
- Колонка подписей до `200px`, колонка значений `56px`. При ширине меньше `~400px` полоса сжимается, подписи остаются читаемыми.

## Доступность

Контейнер имеет `role="list"`, строки `role="listitem"`, полоса `role="meter"` с `aria-valuemin`, `aria-valuemax`, `aria-valuenow` и `aria-valuetext`. Значение читается скринридером текстом, а не только цветом.

## Ограничения

- Только горизонтальные столбцы, один ряд данных. Группировки, оси и подписи делений нет.
- Отрицательные значения не поддерживаются (полоса считается от нуля).

# TextField и SearchField

Два поля ввода из `Fields.tsx`:

- **`TextField`** — обычное текстовое поле с необязательной подписью, подсказкой снизу и иконками. Размеры, отступы, подпись и состояния совпадают с [ComboBox](./ComboBox.md).
- **`SearchField`** — стеклянная строка поиска на `GlassPanel` с кнопкой очистки. Это отдельный компонент со своими размерами (`280 × 36`), он намеренно не выровнен с `TextField` и `ComboBox`.

## Подключение

Компоненты лежат в `Fields.tsx` и стилизуются через `Fields.module.css`. Для работы нужно:

- `GlassPanel`, который `Fields.tsx` импортирует как `../GlassPanel` (он нужен только `SearchField`);
- подключённый в приложении `index.css`: токены `Control*` и классы типографики `BodyTextBlockStyle` и `CaptionTextBlockStyle`.

```tsx
import { TextField, SearchField } from "./Fields";
```

## TextField

### Быстрый старт

```tsx
<TextField
  hint="Имя будет видно другим пользователям"
  label="Имя:"
  onChange={(e) => console.log(e.target.value)}
  placeholder="Введите имя"
/>
```

### Свойства

| Свойство             | Тип                | По умолчанию | Описание                                                                                                                        |
| -------------------- | ------------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `label`              | `ReactNode`        | —            | Вводная подпись                                                                                                                 |
| `labelPlacement`     | `"top" \| "start"` | `"top"`      | Подпись над полем или перед ним (как в macOS)                                                                                   |
| `hint`               | `ReactNode`        | —            | Текст подсказки снизу поля ввода                                                                                                |
| `startIcon`          | `ReactNode`        | —            | Иконка перед текстом (18 × 18)                                                                                                  |
| `endIcon`            | `ReactNode`        | —            | Иконка после текста (18 × 18)                                                                                                   |
| `className`, `style` |                    |              | Применяются к **корневому** элементу                                                                                            |
| остальные            | атрибуты `<input>` |              | `value`, `defaultValue`, `onChange`, `placeholder`, `disabled`, `name`, `id`, `type` (по умолчанию `"text"`)… идут на `<input>` |

`label` и `hint` со значением `null`, `undefined` или `false` не выводятся.

`ref` указывает на `<input>`. Атрибут `size` не поддерживается: ширина задаётся стилями.

### Размеры по умолчанию

Те же значения, что у `ComboBox`. Они лежат в токенах `index.css`, поэтому меняются в одном месте:

| Что                                              | Значение                                             | Токен                                          |
| ------------------------------------------------ | ---------------------------------------------------- | ---------------------------------------------- |
| Высота поля                                      | `32px`                                               | `--ControlHeight`                              |
| Ширина                                           | `auto` (по самому полю ввода, подсказка не влияет), но не шире контейнера | —                                              |
| Горизонтальный отступ текста                     | `10px`                                               | `--ControlPaddingInline`                       |
| Зазор между подписью, полем и подсказкой (`top`) | `6px`                                                | `--ControlLabelGap`                            |
| Зазор между подписью и полем (`start`)           | `12px`                                               | `--ControlLabelInlineGap`                      |
| Скругление                                       | `8px`                                                | `--ControlCornerRadius`                        |
| Рамка                                            | `1px`                                                | `--ControlElevationBorderBrush`                |
| Фокус                                            | контур `2px`                                         | `--AccentFillColorSelectedTextBackgroundBrush` |

Ширина по умолчанию относится ко всему компоненту, вместе с подписью `labelPlacement="start"`.

### Примеры

#### 1. Подпись сверху (по умолчанию)

```tsx
<TextField label="Имя:" placeholder="Введите имя" />
```

#### 2. Подпись слева, как в macOS

```tsx
<TextField label="Имя:" labelPlacement="start" placeholder="Введите имя" />
```

#### 3. С подсказкой снизу (`hint`)

```tsx
<TextField
  hint="Минимум 8 символов, включая цифры"
  label="Пароль:"
  type="password"
/>
```

Подсказка не влияет на ширину поля: она переносится по ширине поля, а не растягивает его. При `labelPlacement="start"` подпись остаётся выровненной по центру самого поля ввода, а подсказка располагается строго под полем.

#### 4. Без подписи

```tsx
<TextField placeholder="Электронная почта" type="email" />
```

#### 5. С иконками

```tsx
<TextField
  endIcon={<CheckIcon />}
  label="Почта:"
  placeholder="name@example.com"
  startIcon={<MailIcon />}
/>
```

Иконка окрашивается через `currentColor`, размер подгоняется под `18 × 18`. Клик по иконке или по отступу фокусирует поле.

#### 6. Управляемый режим

```tsx
const [name, setName] = useState("");

<TextField
  label="Имя:"
  onChange={(e) => setName(e.target.value)}
  value={name}
/>;
```

#### 7. Отключённое поле

```tsx
<TextField
  disabled
  hint="Поле недоступно для редактирования"
  label="Имя:"
  value="Иван"
/>
```

Подпись, подсказка, иконки, текст и фон переходят в отключённое состояние, курсор становится `not-allowed`.

#### 8. Ширина

```tsx
<TextField label="Имя:" style={{ width: 320 }} />
<TextField label="Имя:" style={{ width: "100%" }} />
```

#### 9. В одной форме с ComboBox

`TextField` и `ComboBox` совпадают по высоте, ширине, отступам и фокусу, поэтому в форме выглядят одним набором:

```tsx
<form onSubmit={handleSubmit}>
  <TextField label="Имя:" name="name" />
  <ComboBox label="Город:" name="city" options={cities} />
</form>
```

### Что изменилось по сравнению с прежним `TextField`

- `className` и `style` теперь всегда применяются к корневому `<div>`, а не к `<input>` или `<label>`. Для стилизации самого поля используйте токены или CSS-модуль.
- Ширина по умолчанию `auto` вместо `100%`. Чтобы растянуть поле, передайте `style={{ width: "100%" }}`.
- Высота фиксированная `32px` (раньше `min-height`), горизонтальный отступ `10px` (раньше `12px`).
- Добавлено свойство `hint` для вывода текста подсказки под полем ввода.
- Один и тот же вид с иконками и без них: поле всегда лежит в обёртке.

### Доступность

Подпись — `<label htmlFor>`, связанная с `<input>`. Если передан `hint`, он связывается с `<input>` через атрибут `aria-describedby`. Если `id` не передан, он генерируется автоматически (`useId`). Фокус показывается контуром вокруг всего поля. Анимации отключаются при `prefers-reduced-motion`.

## SearchField

Стеклянная строка поиска: иконка лупы, `<input type="search">` и кнопка очистки, которая появляется, когда в поле есть текст.

### Быстрый старт

```tsx
<SearchField
  onChange={(e) => setQuery(e.target.value)}
  placeholder="Поиск по городам"
/>
```

### Свойства

| Свойство             | Тип                                        | По умолчанию       | Описание                                                                   |
| -------------------- | ------------------------------------------ | ------------------ | -------------------------------------------------------------------------- |
| `width`              | `number \| string`                         | `280`              | Ширина строки                                                              |
| `size`               | `number`                                   | `36`               | Высота строки в пикселях                                                   |
| `placeholder`        | `string`                                   | `"Поиск…"`         | Подсказка                                                                  |
| `onClear`            | `() => void`                               | —                  | Вызывается после нажатия на кнопку очистки                                 |
| `clearLabel`         | `string`                                   | `"Очистить поиск"` | Доступное имя и всплывающая подсказка кнопки очистки                       |
| `className`, `style` |                                            |                    | Применяются к `GlassPanel`                                                 |
| остальные            | атрибуты `<input>` (кроме `size` и `type`) |                    | `value`, `defaultValue`, `onChange`, `disabled`, `name`… идут на `<input>` |

`ref` указывает на `<input>`.

### Примеры

#### 1. Обычная строка

```tsx
<SearchField placeholder="Поиск" />
```

#### 2. Управляемый режим

```tsx
const [query, setQuery] = useState("");

<SearchField
  onChange={(e) => setQuery(e.target.value)}
  onClear={() => console.log("очищено")}
  value={query}
/>;
```

#### 3. Размеры

```tsx
<SearchField size={44} width="100%" />
```

#### 4. Отключённая строка

```tsx
<SearchField disabled placeholder="Поиск недоступен" />
```

### Поведение

Клик в любом месте строки, в том числе по иконке и по отступам, фокусирует поле. Кнопка очистки показывается, пока в поле есть текст и оно не отключено.

Нажатие на кнопку очистки сбрасывает значение через нативный сеттер и отправляет событие `input`, поэтому `onChange` срабатывает как при обычном вводе, и в управляемом режиме родитель получает пустое значение. Затем вызывается `onClear`, и фокус остаётся в поле.

### Доступность

Поле не имеет видимой подписи, поэтому на `<input>` по умолчанию ставится `aria-label`, равный `placeholder`. Чтобы задать другое имя, передайте свой `aria-label`. У кнопки очистки доступное имя и всплывающая подсказка берутся из `clearLabel`. Фокус показывается контуром вокруг всей строки, у кнопки очистки при навигации с клавиатуры есть собственный контур. Анимации отключаются при `prefers-reduced-motion`.

### Ограничения

- Преломление стекла работает только в Chromium, в остальных браузерах `GlassPanel` показывает размытие (это поведение самого `GlassPanel`).
- Подписи (`label`) у `SearchField` нет.
- `size` задаёт высоту строки и не совпадает с одноимённым HTML-атрибутом `<input>`, который не поддерживается.

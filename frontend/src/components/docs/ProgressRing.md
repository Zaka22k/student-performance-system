# ProgressRing

Круговой индикатор прогресса в виде SVG. Работает в двух режимах:

- **неопределённый** (по умолчанию): дуга непрерывно вращается, пока идёт ожидание неизвестной длительности;
- **определённый** (если передан `progress`): кольцо заполняется на заданный процент.

> **Важно:** по умолчанию кольцо **невидимо**. Оно показывается только при `loading`. Без этого свойства `<ProgressRing />` ничего не рисует (см. «Видимость»).

## Подключение

```
ProgressRing.tsx
ProgressRing.module.css
index.css        // должен быть подключён в приложении: токены цвета
```

```tsx
import ProgressRing from "./ProgressRing";
```

Компонент экспортируется как `export default`.

## Быстрый старт

```tsx
// Крутится, пока идёт загрузка
<ProgressRing loading={isLoading} aria-label="Загрузка" />

// Показывает 40 %
<ProgressRing loading progress={40} aria-label="Загрузка файла" />
```

## Свойства

| Свойство | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `loading` | `boolean` | `false` | Показано ли кольцо. При `false` оно скрыто (плавно исчезает), не принимает клики и скрыто от скринридеров |
| `progress` | `number` | — | Процент от 0 до 100. Если задан, режим определённый, иначе неопределённый. Значения вне диапазона обрезаются до 0 и 100 |
| `size` | `number \| string` | `28` | Ширина и высота. Число — пиксели, строка — любое значение CSS (`"2rem"`) |
| `strokeWidth` | `number` | `2.5` | Толщина линии в единицах viewBox (кольцо рисуется в области `24 × 24`). Радиус считается как `(24 − strokeWidth) / 2` |
| `className` | `string` | `""` | Добавляется к классам кольца |
| остальные | атрибуты `<svg>` | | `style`, `aria-label`, `id`, `data-*` и др. идут на `<svg>` |

Остальные атрибуты применяются **последними**, поэтому могут переопределить любой атрибут, который задаёт сам компонент (`width`, `height`, `role`, `aria-hidden`, `viewBox`). Делайте это осознанно.

## Видимость

Кольцо всегда есть в DOM, а `loading` переключает его видимость:

| `loading` | Вид |
| --- | --- |
| `false` | `opacity: 0`, масштаб `0.75`, `pointer-events: none`, `aria-hidden="true"`, вращение на паузе |
| `true` | `opacity: 1`, масштаб `1`, вращение идёт, `aria-hidden="false"` |

Появление и исчезновение анимируются: прозрачность за `0.25s`, масштаб за `0.25s` с лёгким «пружинящим» эффектом. Если кольцо создаётся сразу с `loading`, оно показывается без анимации появления.

Кольцо при этом **занимает место** в разметке даже когда скрыто. Чтобы не резервировать место, не рендерите его вовсе:

```tsx
{isLoading && <ProgressRing loading />}
```

## Режимы

### Неопределённый

Видна дуга в три четверти окружности (75 %), которая вращается с периодом `0.8s`. Передавать `progress` не нужно.

```tsx
<ProgressRing loading />
```

### Определённый

Из-под дуги видна «дорожка» (бледное кольцо, прозрачность `0.2`). Заполнение начинается сверху и идёт по часовой стрелке, изменения значения плавно анимируются (`0.3s`).

```tsx
const [progress, setProgress] = useState(0);

<ProgressRing loading progress={progress} aria-label="Загрузка файла" />
```

`progress={0}` — тоже определённый режим: рисуется пустая дорожка. Чтобы вернуться к неопределённому режиму, передайте `undefined`.

## Примеры

### 1. Размер и толщина

```tsx
<ProgressRing loading size={16} strokeWidth={3} />
<ProgressRing loading size={48} strokeWidth={2} />
<ProgressRing loading size="3rem" />
```

### 2. Цвет

Линия берёт цвет `currentColor`, а он по умолчанию `--TextFillColorSecondaryBrush`. Измените `color` через `style` или свой класс:

```tsx
<ProgressRing
  loading
  style={{ color: "var(--AccentFillColorDefaultBrush)" }}
/>
```

Цвет дорожки (`--TextFillColorTertiaryBrush`) от `color` не зависит.

### 3. Внутри кнопки или строки

```tsx
<Button disabled>
  <ProgressRing loading size={16} />
  Сохранение
</Button>
```

`flex-shrink: 0` у кольца уже задан, поэтому оно не сжимается во flex-контейнере.

### 4. Заменить содержимое на время загрузки

```tsx
{isLoading ? (
  <div style={{ display: "grid", placeItems: "center", minHeight: 240 }}>
    <ProgressRing loading size={32} aria-label="Загрузка" />
  </div>
) : (
  <Content />
)}
```

Именно так это делает компонент `Page` при передаче `onNavigate`, см. [Page.md](./Page.md).

### 5. Плавно скрыть по завершении

Не удаляйте кольцо сразу, а переключите `loading` в `false`. Оно плавно исчезнет:

```tsx
<ProgressRing loading={!done} progress={progress} aria-label="Загрузка файла" />
```

## Анимации и `prefers-reduced-motion`

| Что | Параметры |
| --- | --- |
| Вращение (неопределённый режим) | `0.8s linear infinite`, на паузе, пока кольцо скрыто |
| Появление и исчезновение | прозрачность `0.25s`, масштаб `0.25s`, цвет `0.3s` |
| Изменение `progress` | `stroke-dashoffset` за `0.3s` |
| `prefers-reduced-motion: reduce` | вращение замедляется до `2s` на оборот, но не останавливается |

Длительности и кривые заданы прямо в `ProgressRing.module.css`, токены анимации из `index.css` здесь не используются. Переходы появления и изменения прогресса при `prefers-reduced-motion` остаются.

## Доступность

- У `<svg>` стоит `role="progressbar"`.
- В определённом режиме добавляются `aria-valuenow` (значение после ограничения до 0–100), `aria-valuemin="0"` и `aria-valuemax="100"`. В неопределённом режиме этих атрибутов нет, как и положено для индикатора без известного значения.
- Пока `loading` равен `false`, стоит `aria-hidden="true"`, и скринридер индикатор не видит.
- Доступного имени по умолчанию нет. Передайте `aria-label` (например, `"Загрузка"`) или свяжите кольцо с подписью через `aria-labelledby`.

## Ограничения

- Кольцо нельзя «остановить» без скрытия: вращение идёт, пока `loading` равен `true`.
- Нет свойства для цвета: меняйте `color` через `style` или `className`.
- Скрытое кольцо занимает место и остаётся в DOM (см. «Видимость»).
- Режим определяется только наличием числа в `progress`. Значения `NaN` не обрабатываются отдельно.

## Токены

| Что | Токены |
| --- | --- |
| Цвет линии | `TextFillColorSecondaryBrush` (через `currentColor`) |
| Цвет дорожки | `TextFillColorTertiaryBrush` (прозрачность `0.2`) |
